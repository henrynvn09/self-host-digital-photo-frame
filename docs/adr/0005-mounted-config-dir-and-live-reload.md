# Mounted `magicmirror/config/` directory and hourly Pi config reload

Previously, `docker-compose.yml` bind-mounted individual files (`config.js` and `css/custom.css`), which fails to propagate atomic editor save-via-rename events into the container, and the Raspberry Pi client read `client/config.conf` only once at process startup. Consolidating `custom.css` into `server/magicmirror/config/` and mounting the entire directory (`/opt/magic_mirror/config:ro`) while running MagicMirror's built-in `npm run server:watch` with `reloadAfterServerRestart: true` and `watchTargets: ["config/config.js", "config/custom.css"]` applies server configuration and CSS edits automatically to connected kiosk clients without custom watcher code or manual container restarts. On the Raspberry Pi client, re-reading `client/config.conf` once per hour inside the existing `frame.sh` schedule loop and `pir.py` idle sleep loop picks up schedule and motion timeout edits locally with zero extra daemons or network overhead.
