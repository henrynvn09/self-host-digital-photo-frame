Multi-Round Reshuffled Permutation

Photoframe Architecture

Stateless anniversary sampling with zero database writes. Within each round, daily slices are 100% disjoint without replacement. When a round finishes, the entire deck is reshuffled with a new deterministic seed.

✕ Old Strategy (Static ORDER BY id ASC)
  • ID order was frozen permanently (`0 .. N-1`).
  • After round 1 finished, round 2 returned the exact same photos in the exact same sequence.
  • Under-fill ($N \le K$) repeated the same identical list every single day.
✓ New Strategy (Multi-Round Reshuffled Permutation)
  • Zero duplicates within each round across consecutive days.
  • Fresh random order every round: whole deck is reshuffled with seed = hash(Year, Window, Round).
  • Clean tail flush: finishes previous round cleanly without mixing, then starts fresh.
